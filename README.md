# Mehul Vasava — Professional Portfolio

## Run
Open `index.html` in any modern browser.

## Customize
1. Replace `your.email@example.com` with your real email.
2. Replace LinkedIn and GitHub URLs with your profiles.
3. Add your project links in the project cards.
4. Add a profile photo if desired.
5. Update education/skills as your resume changes.

## Technologies
HTML5, CSS3, Vanilla JavaScript, Google Fonts.

## Features
- Responsive design
- Animated hero/orbit
- Scroll reveal animations
- Scroll progress indicator
- Interactive navigation
- Cursor glow
- Project showcase
- Skills section
- Education timeline
- Contact section
